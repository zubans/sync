# Файлы

`FilesActivity` (пакет `files`) — файловый менеджер, отдельная иконка «Файлы» (`taskAffinity` `com.example.contactsync.files`). Тёмная тема та же, что у главного экрана планшета. На широком экране (от 700 dp) слева боковая панель, на узком места показаны строкой «чипов» над списком.

## Что умеет

- **Места** — внутренняя память и SD-карты (свободное место и полоса заполнения), стандартные папки («Загрузки», «Камера», «Изображения», «Документы», «Музыка», «Видео»), избранное. Папка попадает в избранное через «⋮ → В избранное» у папки или в верхнем меню.
- **Навигация** — путь от корня хранилища, каждый шаг кликабелен. «Назад» снимает выделение, потом очищает поиск, потом ведёт на уровень вверх; в корне хранилища закрывает экран. При возврате вверх список остаётся на прежней позиции. Последняя открытая папка запоминается.
- **Вид** — список или сетка. Сортировка по имени, дате, размеру или типу, повторное нажатие меняет направление. Папки всегда сверху. Имена сравниваются «по-человечески»: `IMG_2` раньше `IMG_10`. Скрытые файлы (с точкой) показываются приглушёнными, если включено «Показывать скрытые».
- **Значки** — превью картинок с поворотом по EXIF, кадр видео, обложка трека, иконка APK. Остальное — «лист» с расширением в цвете вида файла. Превью декодируются в фоне, не больше четырёх сразу, и кешируются в памяти (48 МБ).
- **Поиск** — по имени во всех вложенных папках текущей, без учёта регистра, до 500 результатов. Скрытые папки обходятся, только если включено «Показывать скрытые»; `Android/data` и `Android/obb` — никогда. У результата видно, в какой он папке, «⋮ → Показать в папке» открывает её.
- **Выделение** — долгое нажатие. Над выделенным: выбрать все, копировать, вырезать, переименовать (один), поделиться (только файлы), свойства (один), удалить.
- **Буфер** — «Копировать» или «Вырезать» кладёт файлы в буфер, карточка «Вставить сюда» видна, пока буфер не очищен. После копирования буфер остаётся (можно вставить ещё раз), после переноса очищается. При совпадении имён копия получает номер: `фото.jpg` → `фото (2).jpg`.
- **Операции в фоне** — копирование, перенос и удаление идут с прогрессом (в байтах, для удаления — в штуках) и кнопкой «Отмена». Недокопированный файл при отмене удаляется, уже обработанные остаются. Перенос в пределах раздела — переименованием, между разделами (память ↔ SD-карта) — копированием и удалением.
- **Открытие** — нажатие открывает файл приложением по умолчанию, «Открыть с помощью…» спрашивает, чем открыть. Файлы отдаются через `FileProvider` (`<пакет>.files`, `res/xml/file_paths.xml`). APK открывается системной установкой.
- **Свойства** — тип (MIME), размер (у папки считается обходом дерева), число элементов, дата, путь (можно выделить и скопировать).

Корзины нет: удаление необратимо, поэтому всегда спрашивается подтверждение.

## Доступ к файлам

Менеджер работает с `java.io.File`, а не с Storage Access Framework: SAF не даёт обходить дерево и быстро читать размеры. Поэтому нужен:
- Android 11+ — «Доступ ко всем файлам» (`MANAGE_EXTERNAL_STORAGE`). Диалога для него нет, кнопка «Разрешить» открывает экран настроек; доступ проверяется при каждом возврате в приложение. Через adb: `adb shell appops set com.example.contactsync MANAGE_EXTERNAL_STORAGE allow`.
- Android 8–10 — разрешение на память (`READ/WRITE_EXTERNAL_STORAGE`), на Android 10 — с `requestLegacyExternalStorage`.

Google Play пускает `MANAGE_EXTERNAL_STORAGE` только файловые менеджеры и подобные приложения. Приложение ставится не из Play, так что ограничение не мешает.

## Код

- `FileOps.kt` — чистая логика без Android API: вид файла по расширению, сортировка, размеры, свободное имя, проверка имени, операции с файлами (`FileTransfer`). Покрыта тестами `FileOpsTest`.
- `FilesViewModel.kt` — состояние экрана, места, буфер, фоновые операции. Настройки (папка, сортировка, вид, скрытые, избранное) — в `SharedPreferences` `files`.
- `FileVisuals.kt` — значки, превью и векторные символы. Символов, которых нет в `material-icons-core`, около двадцати, поэтому их контуры вписаны в код, а не подключён `material-icons-extended` (несколько мегабайт в APK).
- `FilesScreen.kt`, `FilesActivity.kt` — экран, открытие файлов и «Поделиться».
